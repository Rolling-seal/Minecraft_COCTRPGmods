# KP 七功能与幕布剧情书（v2.3.1）

> 适用：`coc-2.3.1.jar`，Minecraft 1.20.1 / Forge 47.4.29。
> 这一版把“系统自动发事件卡、玩家点选项”改回 **KP 主导、玩家自由描述** 的跑团方式。
> 玩家在每一幕只会看到一张“幕布”，上面只有这一幕的标题和介绍，没有任何选项按钮。

---

> **中英双语（同一 jar）**：客户端语言为 English 时自动显示英文，简体中文时显示中文。英文说明见 `18-English-Guide.md`；英文界面/剧情截图见 `截图/43`~`49`。

## 一、七项功能对照

| # | 用户要求 | v2.0.0 实现 |
|---|---|---|
| 1 | 只有 KP 能掷骰，帮玩家掷，结果公开 | 玩家 `R` 键与 `/coc roll` 已移除；KP 面板“掷骰”页选玩家/技能/难度/奖惩，点“为选中玩家掷骰”；聊天栏与屏幕浮层对所有在线玩家公开。 |
| 2 | 新一幕只给玩家看介绍，KP 口头模拟选项 | 剧本推进只发“幕布”界面（标题 + 介绍 + 继续），不再发事件卡/选项/自动结算。 |
| 3 | KP 发道具、取玩家道具、道具使用检定 | “道具”页：选玩家 → “发放道具 / 规则”打开常见/自定义道具列表；可把物品 ID 加入道具库并配置技能/目标点数；选中背包道具 → 公开 d100 判定。 |
| 4 | KP 多一本剧情之书 | “剧情书”页 → “主线剧情/支线剧情”打开全屏剧情之书，逐幕显示走向。 |
| 5 | 剧情书分主线/支线，支线写触发与后果 | 剧情之书两个页签；支线页显示所属幕、触发条件、描述、选项、成功/失败后果。 |
| 6 | 自由调幸运/燃运，自由设 HP | 玩家页 → “状态调整 / 燃运”：SAN/HP/MP/幸运可直接输入设定；HP/MP/幸运另有 −5/+5；“HP/MP 全满”。 |
| 7 | KP 能看到玩家背景 | 角色卡左栏直接显示六项背景 + 备注（v2.3 起内联在“伤口”下，可滚动）；KP 查看玩家卡同样可见。 |

## 二、KP 面板五页

按 `K`（或右键 `coc:kp_panel`）打开：

| 页 | 用途 |
|---|---|
| 玩家 | 选玩家；查看角色卡；状态调整/燃运；恢复神志；成长检定；删除角色卡。 |
| 掷骰 | 选技能、难度、奖励/惩罚骰；为选中玩家公开掷骰；也可输入任意表达式公开掷骰。 |
| 道具 | 浏览选中玩家背包；发放道具；道具库/规则；选中道具并做一次公开“使用检定”。 |
| 剧情书 | 选剧本；打开主线/支线剧情之书；开始/结束剧本。 |
| 工具 | 发线索、广播、重载事件/剧本。 |

> 旧的“事件 / 剧本 / 幕”三页已被剧情书取代；“随机事件/自动结算”入口已删除。

## 三、每幕流程（推荐）

1. **KP 准备**：`K` → 玩家页确认玩家都在；剧情书页选剧本 → “开始剧本”。
2. 玩家会看到 **序幕幕布**（剧本名 + 开场介绍），没有选项。
3. KP 口头描述场景，问：“你们先看哪里？谁走在前面？你想怎么做？”
4. 玩家自由描述行动；KP 判断是否需要检定。
5. 需要检定时：
   - KP 面板 → 掷骰页；
   - 选中做动作的玩家；
   - 选技能、难度（常规/困难/极难）、奖励/惩罚骰；
   - 点“为选中玩家掷骰”。
   - 结果会同时出现在所有玩家的聊天栏和屏幕浮层上。
6. KP 根据成功/失败继续描述；不要念选项，不要替玩家做决定。
7. 玩家推进到下一场景时，KP 在剧情书里选中对应幕，点“向玩家显示此幕”；玩家只收到这一幕的幕布介绍。
8. 一幕结束，KP 继续口述，等玩家行动，再显示下一幕。**不要连续点幕**。

### 幕布是什么
- 全屏深色幕布，显示：剧本名、第 N 幕 / 共 N 幕、幕标题、介绍。
- 只有“继续”按钮；没有选项、没有自动检定、没有自动奖励。
- 玩家看完关闭即可；KP 仍然掌握节奏。

## 四、剧情之书怎么用

### 主线剧情
- 左侧是每一幕；右侧显示：
  - 幕标题、概要、触发时机；
  - 场景描述；
  - “可能走向（KP 参考，可自由改）”：每个选项的检定、成功、失败、结果；
  - 该幕可触发的支线名称。
- 底部“向玩家显示此幕”只发幕布，不发选项。

### 支线剧情
- 左侧是支线列表，标注所属幕；
- 右侧显示：
  - **触发**：玩家做了什么才触发；
  - 场景描述；
  - 触发后可能发生：选项、检定、成功/失败后果。
- 支线由 KP 口述，**不自动发给玩家**；想给线索就用“工具 → 发线索”。

### 剧情书里的线索标注
- 每个选项会显示：
  - `成功线索：…` / `失败线索：…` / `线索：…`；
  - 没有线索时显示“无线索”。
- 导入剧本的 `clue` / `successClue` / `failureClue` 会自动进入这些字段。
- 线索只给 KP 参考；要真正发给玩家，仍用“工具 → 发线索”。

### 重要
- 剧情书是 KP 的参考，不是玩家的选项菜单。
- 玩家做出书里没写的行动，完全允许；按后果即兴裁定即可。

## 五、公开掷骰

### 为玩家掷技能
1. 玩家页选中玩家（或在掷骰页保持选中）。
2. 掷骰页选择技能。
3. 选择难度与奖励/惩罚骰。
4. 点“为选中玩家掷骰”。

公开内容：
- 聊天栏：`【玩家 · 技能 · 难度】 d100 / 目标 → 成功等级`
- 所有在线玩家屏幕都会出现检定浮层。
- 大成功/大失败、奖励/惩罚骰明细都会显示。

### 公开掷任意骰
- 掷骰页底部输入 `1d100`、`2d6+3` 等；
- 点“公开掷骰”；
- 同样对所有玩家公开。

> 玩家不能再自己按 `R` 掷骰；`/coc roll`、`/coc check` 等旧命令已移除。玩家要掷骰时，向 KP 说明行动，由 KP 操作。

## 六、道具发放与使用检定

### 发放
1. 玩家页选中目标玩家。
2. 道具页点“发放道具”。
3. 在“发放道具 / 规则”界面：
   - 左侧点常见道具或已加入道具库的物品；
   - 右侧输入数量 1~64，点“发放选中”；
   - 或输入自定义 ID（如 `minecraft:compass`）点“发放自定义”；
   - 点“配置选中规则”/“配置自定义（加入列表）”可把它加入道具库并设置技能与目标点数。
4. 道具直接进入玩家背包；背包满时会掉在玩家脚下。

### 使用
1. 道具页左侧选中玩家背包里的一件道具。
2. 若该物品已配置道具规则，系统自动使用规则里的技能名和目标点数；未配置时才使用“目标”框的临时值（1~100，默认 50）。
3. 点“使用选中道具（公开检定）”。
4. 服务端会：
   - 从玩家背包取走 1 件该道具；
   - 掷 d100；
   - 对所有玩家公开结果（聊天 + 浮层）；
   - 刷新 KP 的道具列表。
5. 成功/失败后果由 KP 口述；系统不自动施加道具效果。

> 道具名称显示为游戏语言中的名称；自定义道具 ID 需要是已注册的物品。

### 道具库与规则
- `config/coc/items.json` 保存：`id`、`skill`（技能 ID，可空）、`target`（1~100）。
- 道具列表中已配置的物品前面有 `★`，右侧显示技能与目标。
- 同一物品可随时重新配置；只影响之后的使用。
- 详细说明见 `17-KP道具库与规则.md`。

## 七、状态调整与燃运

玩家页 → “状态调整 / 燃运”：

- 四个输入框：SAN、HP、MP、幸运；
- “设置全部”：一次写入四个值（自动限制在 0~上限，幸运 0~99）；
- HP/MP/幸运各有 −5/+5；
- “HP/MP 全满”；
- 适合：燃运、剧情伤害、临时恢复、NPC 协助、误伤修正。

> 玩家不能自己改这些数值；只有 KP 能改。

## 八、角色背景

- 玩家或 KP 打开角色卡（`C` 或 KP 玩家页“查看角色卡”）；
- 底部点“背景”；
- 显示：姓名/职业/年龄 + 信念、重要之人、意义非凡之地、宝贵之物、特质、伤口 + 备注；
- 内容多时用滚轮翻阅；小窗口（427×240）也能用。

> v2.0.0 修复了“KP 在小窗口看角色卡看不到背景”的问题。

---

## 八点五、玩家导入新剧本

- 玩家按 `J` → **导入剧本**；KP 也可 `K` → 剧情书 → **导入剧本**。
- 点“选择 JSON 文件”，在文件选择器里选中 `.json`。
- 导入成功后，剧情书列表会多出该剧本；主线/支线自动可用。
- 格式、字段、限制、示例见 `16-玩家剧本导入格式.md`。
- 只接受文本/技能/结果，不执行物品、生成生物或命令；最大 64KB、24 幕。

## 九、已删除/停用的旧功能

| 旧功能 | 处理 |
|---|---|
| 玩家按 `R` 自行掷骰 | 移除按键与命令；服务端拒绝玩家掷骰包。 |
| 事件卡弹窗/选项/自动结算 | 剧本不再发事件卡；仅保留事件数据作为剧情书内容。 |
| 随机事件自动调度 | 服务端 tick 不再调度；入口从 KP 面板移除。 |
| KP 面板“事件/剧本/幕”三页 | 由“剧情书”页 + 剧情之书替代。 |
| `/coc event ...`、`/coc roll`、`/coc check`、`/coc oppose`、`/coc push`、`/coc luck` | 从命令树移除。 |
| `/coc config random|interval` | 从命令树移除（随机调度已停用）。 |

仍保留的旧数据/接口：事件 JSON 仍可作为剧情书内容；旧事件卡类不再被触发。

## 十三、v2.1 / v2.2 追加功能

### 剧本之书（v2.3.1）
- 开始剧本后，所有在线 KP 自动获得/更新一本 `coc:scenario_book`。
- 每个 KP 只保留一本，绑定最新开始的剧本。
- 右键打开剧情之书：左列每一幕，右侧概要、触发、场景、可能走向、支线与线索；当前幕自动选中。
- 仍可点“向玩家显示此幕”；只是发幕布，不发选项。

### KP之书
- 物品 `coc:kp_book`，**KP 进服自动获得**（重生丢失会补发），无需合成；仅 KP 右键打开。
- 8 页：开局 / 掷骰 / 幕布 / 剧情书 / 道具 / 角色卡 / 导入 / 全局设置。
- 给新手 KP 的“下一步该点哪里”，比翻文档快。

### 全局设置
- 物品 `coc:global_settings`，比较器 + 金锭 + 红石 + 书合成；仅 KP 右键打开。
- 可改：允许玩家分配点数、职业点、兴趣点、总点数上限；`-1` 表示自动公式。
- 只影响新角色；已有角色卡不变。

### 角色卡 JSON
- 玩家页 → 选中玩家 → **角色卡 JSON** → 导出/导入。
- 导出用于备份/跨世界迁移；导入覆盖选中玩家。
- 格式见 `21-角色卡JSON格式.md`。

### 道具自定义名称
- 道具规则新增“自定义名称”；保存后进入道具列表并显示 `★`。
- 之后发放的同一物品保留该名称；玩家背包/聊天/使用检定都会显示它。

## 十四、v2.3.0 新增

### 幕布只读选项
- 玩家幕布显示“发生了什么” + 最多三个常规选项。
- 选项只是参考，不能点击；KP 仍用掷骰/口述裁定。

### 线索点击发送
- 剧情书的成功/失败/直接线索行可点击。
- 选择在线玩家后，线索进入其日志，可连续发送。

### 角色卡内联背景
- 背景六项和备注显示在角色卡左栏“伤口”下面。
- 左栏滚轮查看，底部有提示和滚动条；不再需要“背景”按钮。

### KP 神志不清
- 玩家页“恢复神志 / 神志不清”并排。
- 神志不清不扣 SAN，随机触发一次临时疯狂并公开广播。

### 全局设置扩展
- 在KP之书左侧点击“全局设置”条目，直接打开设置面板。
- 可设置初始幸运、初始 HP、初始 SAN 的最小/最大范围；`-1` 使用默认。
- 技能点总和上限继续保留。

### 文件选择器
- Windows 使用 PowerShell/WinForms 原生对话框，绕过 Java headless 检测。
- 非 Windows 桌面回退 AWT；真正无桌面环境给出提示。
