## 2026-11-19 · v2.0.0 · KP 主导改版（七功能 + 幕布 + 剧情书）

### 用户反馈
- 旧版“所有玩家收事件卡、点选项、自动结算”自由度太低。
- 要求 KP 独有掷骰、幕布式分幕、道具发放/使用检定、剧情之书（主线/支线）、自由调幸运/HP、KP 能看到玩家背景，并删除不要的功能。

### 已完成
1. **KP 专属公开掷骰**
   - 移除玩家 `R` 键、玩家掷骰界面入口与 `/coc roll|check|oppose|push|luck` 命令。
   - 新增 `C2SKpRoll` + `CheckService.rollForKeeper`：KP 选玩家/技能/难度/奖惩，或公开掷任意表达式。
   - 结果通过聊天 + `S2CRollResult` 广播给所有在线玩家；目标玩家同步技能成长标记。
2. **幕布式分幕**
   - 新增 `S2CActCurtain` / `CurtainScreen`。
   - `ScenarioManager` 不再调用事件卡；开始发序幕幕布，每幕发标题+介绍幕布，结束发尾声幕布。
   - 玩家界面没有选项；KP 用剧情书口述。
3. **KP 道具工具**
   - 新增 `S2CItemList`、`ItemView`、`ItemPickerScreen`、`ItemService`。
   - 道具页：查看选中玩家背包、常见/自定义道具发放（1~64）、选中道具后取走 1 件并公开 d100 使用检定。
4. **剧情之书**
   - 新增 `S2CBookData`、`BookView`、`StoryBookScreen`、`BookDataBuilder`。
   - 主线：每幕概要/触发/描述/选项/成功失败/可触发支线；支线：触发条件/所属幕/描述/选项/后果。
   - KP 面板“剧情书”页提供“主线剧情/支线剧情”入口；主线页“向玩家显示此幕”只发幕布。
   - 为 15 个支线 JSON 补齐 `triggerHint`。
5. **自由调整幸运/HP**
   - 玩家页新增“状态调整 / 燃运”界面：SAN/HP/MP/幸运设置全部、HP/MP/幸运 ±5、HP/MP 全满。
   - 服务端新增 `hp_set/mp_set/luck_set` 动作。
6. **KP 查看玩家背景**
   - 角色卡底部新增“背景”按钮；新增 `BackstoryScreen`，小窗口也可滚动查看六项背景+备注。
7. **删除旧功能**
   - 停用随机事件调度；移除 `/coc event ...`、`/coc config random|interval`。
   - 新 KP 面板取消“事件/剧本/幕”三页，改为玩家/掷骰/道具/剧情书/工具。
   - 旧事件数据保留，仅作为剧情书内容来源。

## 2026-11-20 · v2.0.0 · 玩家剧本导入

### 需求
- 玩家可以导入规定格式的 JSON，把新剧本加入 KP 的剧情之书。

### 已完成
1. **单文件格式 `coc-scenario-v1`**
   - 顶层：format/id/title/description/intro/outro/sanReward/acts。
   - 每幕：title/summary/trigger/description/options/sideEvents。
   - 选项只接受 text/skill/difficulty/success/failure/outcome 文本；不执行 effects、物品、生成生物或命令。
   - 文档 `16-玩家剧本导入格式.md` 附完整示例。
2. **服务端导入**
   - `ScenarioImportService`：Gson 解析 + 严格校验（id/长度/幕数/选项数/技能/难度/SAN 奖励表达式/64KB）。
   - 转成标准 `ScenarioDef` + `EventDef` JSON，写入 `config/coc/scenarios/` 与 `config/coc/events/`，调用 `EventRegistry.reload()`。
   - 失败自动清理临时/已写文件并给出具体错误；成功广播并刷新在线 KP 面板。
   - 新包 `C2SImportScenario` / `S2CImportResult`；协议版本升到 3。
3. **客户端导入界面**
   - 新增 `ImportScenarioScreen`：选择 JSON 文件、生成示例文件、返回；显示错误/成功。
   - 入口：玩家 `J` 线索日志 → “导入剧本”；KP `K` → 剧情书 → “导入剧本”。
4. **剧情书联调**
   - 导入后 `KpView.Scenario` 列表出现新剧本；主线/支线剧情书自动读取。
   - 支线触发/后果使用导入文本；主线“向玩家显示此幕”仍只发幕布。

### 验证
- 客户端实测导入 2 幕剧本：`COC 事件加载完成：81 个事件，5 个剧本`；剧情书显示新剧本、选项、支线。
- 截取导入/剧情书/工具页/道具规则/线索标注 10 张图（33~42）。
- 专用服务器 `SELFTEST OK · 事件 75 · 剧本 3`；最终 jar 无 `ClientAutoTest`。
- 最终 jar `coc-2.0.0.jar` 608,475 字节。

### 已知限制
- 导入数据是服务器级世界内容，任何玩家都可添加；当前未加“仅 KP/白名单”开关。
- 使用系统文件选择器（AWT FileDialog）读取 `.json`；文件选择器在部分 Linux/无桌面环境不可用。
- 导入剧本只用于剧情书内容，不会自动执行事件效果；KP 口述/公开掷骰。

## 2026-11-20 · v2.0.0 · 剧情书线索 + KP 道具库/规则

### 用户反馈
1. 工具页文本错位重叠。
2. 导入剧本应标注每个选项会获得什么线索（或没有线索）。
3. KP 应能按物品 ID 手动把物品加入物品列表。
4. KP 应能自定义每件物品对应什么技能判定点数。

### 已完成
1. **工具页排版**
   - 发放线索/广播标题、输入框、按钮分行；数据警告区下移；剧情书页按钮下移。截图 `37`。
2. **剧情书线索标注**
   - `BookDataBuilder` 输出 `success_clue/failure_clue/clue`（来自 `Outcome.handout`）。
   - `StoryBookScreen` 每个选项显示“成功线索/失败线索/线索”；无则显示“无线索”。
   - 导入格式新增 `clue` / `successClue` / `failureClue`，允许无线索。
   - 截图 `41`。
3. **KP 道具库**
   - 新增 `ItemLibrary`，持久化 `config/coc/items.json`（物品 ID + 技能 + 目标点数）。
   - KP 道具页“发放道具 / 规则”：常见/自定义/道具库列表；可用物品 ID 加入列表。
   - KpData 下发 `item_rules`；`KpView` 解析。
   - 截图 `38`~`40`。
4. **每件物品的技能/目标**
   - `ItemRuleScreen`：技能 ID（可空）+ 目标点数 1~100。
   - `ItemService.use` 服务端查规则：有规则用规则技能/目标，无规则用临时目标；客户端显示规则。
   - 实测 `【Tester · Torch · 侦查】 21 / 65 → 困难成功`。
   - 持久化测试：`config/coc/items.json` 保留 `minecraft:torch / spot_hidden / 65`。
5. **文档**
   - 新增 `17-KP道具库与规则.md`；更新 `16`（线索字段）、`15/05/11`。

### 验证
- 编译 94 个源文件通过；最终 jar `coc-2.0.0.jar` 608,475 字节（约 590 KB）。
- 客户端实测：工具页无重叠、道具规则列表/配置页、规则生效、剧情书线索标注。
- 专用服务器自检通过；最终 jar 无 autotest。
