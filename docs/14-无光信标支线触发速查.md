# 无光信标 · 支线触发速查（v2.0.0）

> 适用：`lightless_beacon`（无光信标，11 幕，5 个支线）
> 用途：KP 在玩家做出特定动作时，快速判断该触发哪个支线、会发生什么。
> v2.0.0 起：**不再用事件卡/分类筛选**。打开 `K` → 剧情书 → **支线剧情**，按下面的触发条件口述。

---

## 一、支线触发总表

| 支线 | 所属幕 | 玩家做了什么才触发 | 常由哪个主线行动引出 |
|---|---|---|---|
| 会数钱的金币 | 第 3 / 6 幕 | 捡起金币并**收进口袋**，或盯着金币看 | 第 3 幕“搜海滩”；第 6 幕“撬开木箱” |
| 守塔人的日志 | 第 4 幕 | 专门**读日志 / 翻到最后一页 / 撕页** | 第 4 幕“搜屋子” |
| 无线电里的第三个人 | 第 5 幕 | 用无线电后**继续回应 / 调频 / 问“你是谁”** | 第 5 幕“用无线电” |
| 石槽祭坛 | 第 7 幕 | 进入海蚀洞后**检查石槽 / 金币 / 墙上符号** | 第 7 幕“观察仪式” |
| 艾伦的金币 | 第 8 幕 | 注意艾伦口袋、**逼问或安慰后追问金币** | 第 8 幕“安抚他”/“追问” |

---

## 二、具体触发话术

### 1. 会数钱的金币（第 3/6 幕）
**玩家说：**
- “我把金币收起来 / 放进口袋 / 数一数。”
- “我盯着这些金币看。”

**KP 操作：**
1. 打开 `K` → 剧情书 → 支线剧情 → 选中“会数钱的金币”，看触发与后果；
2. 口述金币震动/数钱声；
3. 需要时在掷骰页公开掷“神秘学/侦查”，或让玩家自己描述；
4. 用工具页发线索/道具。

**不该触发：** 玩家只是看了一眼，或把金币留在原地。

---

### 2. 守塔人的日志（第 4 幕）
**玩家说：**
- “我翻开日志读。”
- “我翻到最后一页。”
- “我把最后一页撕下来。”

**KP 操作：** 剧情书 → 支线剧情 → “守塔人的日志”；口述日志内容；可发线索“它们只要金币。把金币还回去，别开灯。”

**不该触发：** 玩家只搜到日志但没读，直接塞进包里就走。

---

### 3. 无线电里的第三个人（第 5 幕）
**玩家说：**
- “我按下通话键回应。”
- “我问对方是谁。”
- “我继续调频 / 继续听。”

**KP 操作：** 剧情书 → 支线剧情 → “无线电里的第三个人”；口述第三个人的呼吸/报坐标；必要时公开掷“聆听”。

**不该触发：** 玩家只成功联系海岸警卫队，然后立刻关掉无线电。

---

### 4. 石槽祭坛（第 7 幕）
**玩家说：**
- “我检查石槽。”
- “我摸那些符号。”
- “我看金币堆 / 看祭坛底部。”

**KP 操作：** 剧情书 → 支线剧情 → “石槽祭坛”；口述“归还”刻字；可公开掷“神秘学”。

**不该触发：** 玩家只是远远看一眼，没靠近祭坛。

---

### 5. 艾伦的金币（第 8 幕）
**玩家说：**
- “我盯着他口袋。”
- “我问他是不是也拿了金币。”
- “我搜他身 / 翻他口袋。”

**KP 操作：** 剧情书 → 支线剧情 → “艾伦的金币”；口述两枚金币；可公开掷“心理学/恐吓/魅惑”。

**不该触发：** 玩家只安抚他两句，没注意金币，也没追问。

## 三、支线里的“特殊选项”与后果

| 支线 | 特殊选项 | 会发生什么 |
|---|---|---|
| 会数钱的金币 | **收进口袋**（神秘学） | 成功：获得金币，开始梦见海底有人数钱；失败：金币变成牙齿 |
| 会数钱的金币 | 把金币放回去 | 金币停止震动，安全；没有额外奖励 |
| 守塔人的日志 | **读完整本**（图书馆） | 得知马修把金币卖给盐沼镇、门外没有脚印 |
| 守塔人的日志 | **撕下最后一页** | 获得纸片：“它们只要金币。把金币还回去，别开灯。” |
| 无线电里的第三个人 | **回应**（聆听） | 对方叫出你的名字，说“别让灯灭” |
| 无线电里的第三个人 | 关闭无线电 | 静电停止，但房间里多出第三个呼吸声 |
| 石槽祭坛 | **检查祭坛**（神秘学） | 得知金币是“租金”，拿走的人会被追讨；获得神话知识 |
| 石槽祭坛 | **破坏符号**（格斗） | 蓝光暗一瞬，年轻者尖叫，但祭坛没有毁 |
| 艾伦的金币 | **逼问**（恐吓） | 艾伦交出两枚金币：“它们说只要还回去就没事” |
| 艾伦的金币 | **安慰**（魅惑） | 艾伦告诉你海蚀洞位置，并说“它们怕火” |

> 这些支线没有“连锁下一张事件卡”。它们只给线索、物品、SAN/HP 变化，不自动推进主线幕次。

## 四、主线里的“特殊选项”与后续

| 幕 | 选项 | 后续 / 影响 |
|---|---|---|
| 第 3 幕 | **先去船屋** | 可以提前触发第 8 幕“船屋里的幸存者”（用剧情书直接显示第 8 幕） |
| 第 5 幕 | **用无线电成功** | 记录“海岸警卫队黎明到”，影响第 11 幕救援 |
| 第 6 幕 | **撬开木箱** | 获得金币；若收进口袋 → 支线“会数钱的金币” |
| 第 7 幕 | **观察仪式成功** | 得知金币是“归还”的租金 → 支线“石槽祭坛” |
| 第 8 幕 | **追问艾伦** | 直接拿到两枚金币；若继续追问 → 支线“艾伦的金币” |
| 第 9 幕 | **点亮灯塔** | 可能引来救援，也可能激怒洞里的东西 |
| 第 9 幕 | **只发无线电** | 更安全的救援路线，但需要撑到黎明 |
| 第 10 幕 | **用金币引开** | 需要队伍手里还有金币；否则无效 |
| 第 11 幕 | **带走金币** | 结局留下“租金未清”的钩子 |

## 五、操作顺序（重点）

1. KP 口述当前主线场景；
2. 玩家做出支线动作；
3. 打开 `K` → 剧情书 → 支线剧情 → 选中对应支线，阅读触发/后果；
4. 口述支线内容；需要检定就在掷骰页公开掷；
5. 支线结束，回到当前主线场景；
6. **不要**用“显示此幕”来发支线；支线不自动发给玩家。

---

## 六、6 人团注意

- 只对**做动作的那个人**口述支线；其他人旁听/协助。
- 两人搭档一起做 → 以主行动者为核心，另一人可给 +1 奖励骰。
- 一次最多 1 个支线；不要连着刷。
- 支线不是主线必需品；玩家没触发就跳过，不影响通关。
- 支线没讲完，不要显示下一幕。

---

## 七、一句话速记

**金币收口袋 → 金币支线；读日志 → 日志支线；继续用无线电 → 无线电支线；摸石槽 → 祭坛支线；追问艾伦金币 → 艾伦支线。**
