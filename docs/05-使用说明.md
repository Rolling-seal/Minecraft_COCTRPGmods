# 使用说明 · 克苏鲁的呼唤（v2.3.0）

适用：Minecraft 1.20.1 · Forge 47.4.29 · 客户端/专用服务器均可。
安装：把 `coc-2.3.0.jar` 放入实例 `mods\`；客户端与服务器必须同一版本。旧 `coc-1.x/2.0.x.jar` 请删除。

> v2.0.0 是“KP 主导”改版：玩家不再自行掷骰、不再收到自动事件卡；每一幕只收到一张幕布介绍。
> v2.1.0 新增 **KP之书**、**全局设置** 两个物品，角色卡 JSON 导出/导入，以及道具自定义名称。
> v2.1.1 起 KP之书改为 **KP 进服自动获得**，不再需要合成。
> v2.2.0 新增 **剧本之书**：开始剧本后自动发给 KP，右键快速翻阅每一幕。
> 详细七功能说明见 `15-KP七功能与幕布剧情书.md`。

---

> **中英双语（同一 jar）**：客户端语言为 English 时自动显示英文，简体中文时显示中文。英文说明见 `18-English-Guide.md`；英文界面/剧情截图见 `截图/43`~`49`。

## 1. 第一次进入

- 进入世界后约 3 秒自动打开角色创建；也可按 `C` 或 `/coc create`。
- 创建流程：属性/职业 → 技能点 → 背景/备注 → 确认。
- SAN 初始 = POW；HP=(CON+SIZ)/10；MP=POW/5；最大 SAN=99−神话。

## 2. 按键

| 按键 | 功能 |
|---|---|
| `C` | 角色卡（底部有“背景”） |
| `J` | 线索日志 |
| `K` | KP 面板（仅 KP） |

- 玩家不再有 `R` 掷骰键；需要检定时告诉 KP 你要做什么。
- 暂停菜单左上角有“克苏鲁设置”，可关闭低 SAN 特效。

## 3. 玩家怎么玩

1. 描述角色行动：“我想检查壁炉 / 我问邻居 / 我躲到门后。”
2. KP 判断是否检定；需要时由 KP 在面板里为你公开掷骰。
3. 结果对所有玩家公开；你根据成功/失败描述角色反应。
4. 每一幕开始时，屏幕会出现一张 **幕布**：只有标题和介绍，没有选项。看完点“继续”。
5. 幕布之外，行动完全自由；不要等系统给选项。
6. 线索会进入 `J` 日志；角色卡底部“背景”可查看自己的六项背景。

## 4. KP 怎么开团

1. 玩家建卡；纯 KP 不需要建卡。
2. 按 `K` 打开面板：
   - **玩家**：选人、查看角色卡、状态调整/燃运、恢复神志、成长、删除角色。
   - **掷骰**：选玩家/技能/难度/奖惩 → 为玩家公开掷骰；也可公开掷任意表达式。
   - **道具**：发放道具；选中玩家背包道具做公开使用检定。
   - **剧情书**：选剧本 → 开始；打开主线/支线剧情之书；显示某一幕。
   - **工具**：发线索、广播、重载。
   - **玩家**页下方：**角色卡 JSON**，导出/导入选中玩家的角色卡。
3. 不熟悉操作时，右键 **KP之书** 查看 8 页游戏内指南；右键 **全局设置** 调整新角色点数。
4. 开始剧本后，右键自动获得的 **剧本之书** 快速翻阅每一幕。
4. 剧情书页选剧本 → “开始剧本”；玩家收到序幕幕布。
5. 口述场景 → 问玩家行动 → 需要时公开掷骰 → 玩家推进后，在剧情书里点“向玩家显示此幕”。
6. 一幕结束时继续口述；**不要连续点幕**，也不要用自动结算代替玩家选择。

## 5. 幕布与剧情书

- **幕布**：全屏深色界面，显示剧本名、第 N 幕/共 N 幕、幕标题、**发生了什么**，以及最多 **三个只读的常规选项**；只有“继续”。选项不能点击，仅作参考，由 KP 裁定。
- **主线剧情**：每幕概要、触发时机、场景描述、可能走向（选项/检定/成功/失败）、可触发支线。
- **支线剧情**：触发条件、所属幕、描述、选项与后果；由 KP 口述，不自动发给玩家。
- “向玩家显示此幕”发幕布（含只读选项）；玩家不能点击选项。
- 每个选项会标注成功/失败/直接结果对应的线索；没有线索显示“无线索”。
- 线索行可以点击：选择在线玩家后，线索会进入该玩家的日志。

## 6. 公开掷骰

### 技能检定
1. 玩家页选中玩家。
2. 掷骰页选技能、难度（常规/困难/极难）、奖励/惩罚骰。
3. 点“为选中玩家掷骰”。
4. 所有在线玩家收到聊天结果 + 屏幕浮层。

### 任意骰
- 输入 `1d100`、`2d6+3` → “公开掷骰”。

玩家不能自己掷骰；旧 `/coc roll`、`/coc check` 等命令已移除。

## 7. 道具

### 发放
1. 玩家页选中目标。
2. 道具页 → “发放道具”。
3. 选常见道具（火把/提灯/纸/书/地图/铁剑/弓/绳子等），填数量 1~64 → “发放选中”；
   或输入自定义 ID（如 `minecraft:compass`）→ “发放自定义”。
4. 道具进入玩家背包；满了会掉在脚下。
5. 自定义名称：在“配置选中规则/配置自定义”界面填写 **自定义名称**，保存后列表里显示 `★ 名称`，之后发放的这件物品都会带这个名称。

### 使用
1. 道具页左侧选中玩家背包里的一件道具。
2. 输入目标值 1~100（默认 50）。
3. 点“使用选中道具（公开检定）”。
4. 服务端取走 1 件、掷 d100、对所有玩家公开结果；成功/失败后果由 KP 口述。
6. 道具规则：KP 可在“发放道具 / 规则”中把物品 ID 加入道具库，并设置 **自定义名称**、技能与目标点数；已配置的物品使用规则目标，未配置的用临时目标。详见 `17-KP道具库与规则.md`。

## 8. 状态调整 / 燃运

玩家页 → “状态调整 / 燃运”：
- SAN / HP / MP / 幸运四个输入框；
- “设置全部”一次写入（自动限制上限）；
- HP/MP/幸运 −5/+5；
- “HP/MP 全满”。

## 9. 角色背景

角色卡左侧面板直接显示：信念、重要之人、意义非凡之地、宝贵之物、特质、伤口，以及 **备注**。
内容在“伤口”下面继续排列；在左侧面板上滚轮即可向下查看（底部有“滚轮查看背景/备注”提示和滚动条）。
不再需要点进单独的“背景”界面；427×240 小窗口同样可用。

## 10. SAN 与疯狂

- KP：`/coc sancheck <成功损失> <失败损失> [玩家]`，例 `/coc sancheck 1 1d6`。
- 单次损失 ≥5：临时疯狂（1d10 小时 + 发作表）。
- 单日损失达到损失前 SAN 的 1/5：不定期疯狂，获得恐惧症/狂躁症。
- SAN 归零：永久疯狂；KP 可用 `/coc san set` 恢复。
- KP 玩家页新增 **“神志不清”** 按钮：不扣 SAN，直接把选中玩家推入一次临时疯狂（随机发作 + 效果 + 公开广播）。
- 剧本结束按 `sanReward` 恢复 SAN；`/coc growth [玩家]` 结算成长。

## 12. 剧本

- `the_haunting` 鬼屋（11 幕，5 支线）：官方《The Haunting》结构的中文原创改编，适合新手。
- `lightless_beacon` 无光信标（11 幕，5 支线）：官方《The Lightless Beacon》结构的中文原创改编，适合第二场。
- `dark_whispers` 黑暗中的低语（12 幕，5 支线）：原创村庄/地窖/梦境长团。

## 12.5 玩家导入剧本

- 任何玩家都可以按 `J` → **导入剧本**，或 KP 按 `K` → 剧情书 → **导入剧本**。
- 点“选择 JSON 文件”，在文件选择器里选中 `.json`。
- Windows 下使用 PowerShell 原生文件对话框，不依赖 Java AWT 的 headless 检测；其它桌面系统回退 AWT。
- 成功后 KP 的剧情之书会多出这个剧本；详情见 `16-玩家剧本导入格式.md`。
- 格式只允许文本/技能/成功失败，不执行物品、生成生物或命令；最大 64KB、24 幕。

## 13. 已移除的旧功能

- 玩家自行按 `R` 掷骰、`/coc roll`、`/coc check`、`/coc oppose`、`/coc push`、`/coc luck`。
- 自动事件卡、选项、2 分钟自动结算。
- 随机事件自动调度、`/coc config random|interval`。
- KP 面板旧“事件/剧本/幕”三页（由剧情书替代）。

事件 JSON 仍保留，作为剧情书内容来源；不再自动弹卡。

## 14. v2.2.0 新增物品与角色卡 JSON

### 14.1 KP之书（`coc:kp_book`）
- **不用合成**：KP 进入世界时自动放入物品栏；重生时若丢失也会补发。
- 仅 KP 可右键打开；8 页：开局 / 掷骰 / 幕布 / 剧情书 / 道具 / 角色卡 / 导入 / 全局设置。
- 创造模式“工具与实用物品”页也能直接取。

### 14.2 全局设置（`coc:global_settings`）
- 合成：比较器 + 金锭 + 红石 + 书（无序合成）。
- 仅 KP 可右键打开；也可从 **KP之书 → 全局设置页 → “打开全局设置”** 进入。
- 可设置：
  - 是否允许玩家自行分配点数；
  - 职业点（`-1` = 按职业公式）；
  - 兴趣点（`-1` = INT×2）；
  - 技能点总和上限（`-1` = 不额外限制）；
  - 初始幸运范围（最小/最大，`-1` = 默认掷骰）；
  - 初始血量范围（最小/最大，`-1` = 体质/体型公式）；
  - 初始 SAN 范围（最小/最大，`-1` = POW）。
- 范围会应用到**新角色创建**：在范围内随机；最小=最大即为固定值；只影响新角色，已有角色卡不变。
- 设置保存在服务端 `config/coc-server.json`，并同步给客户端。

### 14.3 角色卡 JSON 导出/导入
- KP 面板 → **玩家** → 选中玩家 → **角色卡 JSON**。
- **导出**：服务器把选中玩家的角色卡转成 `coc-character-v1` JSON，客户端弹出保存对话框，保存为 `.json`。
- **导入**：客户端选择 `.json`，服务器校验后覆盖**选中玩家**的角色卡；玩家名与 UUID 保持为当前玩家。
- 会保留：属性、年龄、职业、HP/MP/SAN/神话、技能、成长标记、临时/不定期疯狂、恐惧症/狂躁症、背景、备注、线索。
- 导入会清空该玩家的临时事件/检定状态；建议先导出备份。
- 字段说明与示例见 `21-角色卡JSON格式.md`。

### 14.4 剧本之书（`coc:scenario_book`）
- **不用合成**：KP 点击开始剧本后，所有在线 KP 自动获得/更新一本。
- 每个 KP 只保留一本；开始新剧本时更新为当前剧本，不会堆满背包。
- 右键打开 **剧情之书**：左边每一幕，右边该幕的概要、触发、场景、可能走向、支线和线索。
- 当前幕会自动选中；可点“向玩家显示此幕”发幕布。
- 书中的剧本绑定保存在物品 NBT；没有绑定/没有进行中的剧本时会给出提示。

## 15. v2.3.0 新增/调整

### 15.1 幕布只读选项
- KP 点“向玩家显示此幕”后，玩家幕布显示：
  - 发生了什么；
  - 最多三个常规选项；
  - 选项不可点击，只供参考；结果仍由 KP 裁决。

### 15.2 剧情书线索点击发送
- 剧情书里的“成功线索 / 失败线索 / 线索”行现在可点击。
- 点击后打开“发送线索”界面，选择一名有角色卡的在线玩家；线索进入其日志。
- 可连续发给多名玩家，或返回继续翻阅。

### 15.3 角色卡内联背景
- 背景六项与备注直接排在角色卡左栏“伤口”下面；滚轮查看，不再需要单独的“背景”按钮。

### 15.4 KP 神志不清
- KP 玩家页 **恢复神志 / 神志不清** 并排。
- 神志不清不扣 SAN，随机触发一次临时疯狂并公开广播。

### 15.5 文件选择器
- Windows 使用 PowerShell + WinForms 原生对话框，绕过 `GraphicsEnvironment.isHeadless()`。
- 若 PowerShell 不可用且 AWT 非 headless，自动回退 AWT；真正无桌面环境会显示明确提示。
