> 测试日期：2026-11-18。环境：Windows 11 · Java 17.0.19 · Forge 47.4.29 · MC 1.20.1。

## 1. 专用服务器测试

**服务器**：Forge 1.20.1-47.4.29 官方安装器安装的专用服务器（临时目录 `testserver`），Flat 世界，offline-mode。

**步骤**
1. `mods/` 放入 `coc-1.0.0.jar`。
2. 启动服务器，等待 `Done (2.004s)`。
3. 控制台执行：
   - `coc debug selftest`
   - `coc event list`
   - `coc scenario list`
   - `coc config random false`
   - `coc kp list`
4. `stop` 正常关服。

**结果**
- 模组正常加载，网络通道注册成功；无客户端类加载错误。
- 事件加载：**32 个事件，1 个剧本**。
- `SELFTEST OK · 事件 32 · 剧本 1`。
- 事件列表、剧本列表、随机事件开关、KP 名单命令均正常。
- 日志无 `ERROR` / `Exception` / `NoClassDefFoundError`。
- 关服时正常保存世界与 `coc_world_data`。

## 2. 客户端测试

**方式**：用 Forge 47.4.29 客户端 + 1.20.1 assets + 本地测试世界 `COC_Test` 启动（绕过 PCL UI 的等价手动启动），`mods` 中同时保留 voicechat 模组以验证共存。

**结果**
- 客户端正常启动，资源包/声音/字体加载正常。
- 模组客户端初始化：`克苏鲁的呼唤：客户端按键已注册`。
- 集成服务器加载：`COC 事件加载完成：32 个事件，1 个剧本`。
- 玩家 `Tester` 成功进入世界；voicechat 同时正常初始化，无冲突。
- 全流程自动冒烟测试（测试代码 `ClientAutoTest` 仅用于本轮测试，**已从最终 jar 移除**）：
  1. 打开角色创建界面（属性/职业页、技能页、背景页）。
  2. 发送创建角色包 → 服务端创建成功（`Tester · 侦探 · SAN 60/99`）。
  3. 打开角色卡、掷骰界面、KP 面板（玩家/事件/剧本/工具四页）、设置、线索日志。
  4. 执行 `/coc roll 1d100`，结果正常回调到掷骰界面。
  5. 发放线索并打开日志，线索与正文正常显示。
  6. 设置 SAN=10 → 低 SAN 后处理加载。
  7. 触发事件「雾中低语」→ 事件卡打开 → 选择选项 → 检定失败 → SAN -1 → 正常结算。
  8. 关闭事件结果界面，设置 SAN=0 → 永久疯狂 + 疯狂后处理。

- 全程无 `ERROR` / `Exception` / 崩溃。
- 已知无害警告：`Shader color_convolve/wobble could not find uniform named InSize`（原版程序里该 uniform 未参与实际计算，PostChain 设置时提示；不影响加载与画面）。
