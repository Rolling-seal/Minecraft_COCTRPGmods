## 调研 1：是否存在"MC 1.20.1 Forge 克苏鲁跑团"整合作品

**检索渠道**
- Modrinth API：`query=sanity`、`query=cthulhu`，筛选 `versions:1.20.1`、`categories:forge`
- CurseForge 站内搜索（WebSearch）：`site:curseforge.com "Call of Cthulhu" Minecraft mod 1.20.1`
- 中文检索：`我的世界 克苏鲁的呼唤 跑团 模组 1.20.1 角色卡 骰子`
- 参考上一项目《丧尸生存》源码与开发记录（本机）

**结果**
1. Modrinth 上的理智类模组：
   - [Sanity: Descent Into Madness](https://modrinth.com/mod/sanity-descent-into-madness)：饥荒式理智值，1.20.1 Forge 可用，但不是 COC 规则。
   - [Sanity: Renewed](https://modrinth.com/mod/sanity-renewed)：同类，1.20.1/1.21.1。
   - 这些模组没有角色卡、职业、技能点、d100 成功等级、KP 事件、剧本。
2. CurseForge 的克苏鲁主题模组：
   - [Cthulhu Creatures](https://legacy.curseforge.com/minecraft/mc-mods/cthulhu-creatures)：泰拉瑞亚风格怪物/Boss。
   - [Eldritch End](https://www.curseforge.com/minecraft/mc-mods/eldritch-end)：洛夫克拉夫特主题末地生态/Boss。
   - [Tinker's Newlife](https://www.curseforge.com/minecraft/mc-mods/tinkers-newlife)：匠魂附属，洛夫克拉夫特主题材料。
   - 均为"克苏鲁题材内容模组"，不是跑团规则/角色卡/KP 工具。
3. 中文搜索结果：只有网页跑团工具（[跑团模拟器](https://zhyslostland.github.io/paotuan-simulator/)、[CoC7 在线角色卡](https://vvd.world/t/investigator)、[海豹核心 CoC7 指令](https://docs.sealdice.com/use/coc7.html)），没有 Minecraft 1.20.1 整合模组。

**结论**
- 不存在可直接安装即满足需求的现成模组。
- 可复用的是"规则设计/数据结构"思路，不复用代码（避免许可与版本风险）。
- 决定自研 `coc` 模组：规则层 + 角色卡 + 事件/剧本 + KP 工具 + 客户端特效。

**未采用方案及原因**
- 集成 Sanity 类模组：玩法是饥荒式理智条，与 COC 的 SAN 检定、疯狂、角色卡不兼容；且会引入额外依赖。
- 集成克苏鲁生物模组：只提供怪物，不解决跑团流程；可能与本项目事件生成实体冲突。
- 使用网页跑团工具：无法在 MC 内共享角色卡/KP 事件/世界状态。

## 调研 2：低 SAN 屏幕扭曲如何实现（1.20.1 Forge）

**检索/验证渠道**
- 解包本机 1.20.1 客户端资源 jar：`client-1.20.1-20230612.114412-extra.jar`
- 检查原版 `assets/minecraft/shaders/post/*.json` 与 `shaders/program/*.json|fsh|vsh`
- `javap` 检查 `GameRenderer`、`PostChain`、`PostPass`、`EffectInstance` 的公开 API

**结果**
- 原版自带 post 效果：
  - `minecraft:shaders/post/desaturate.json`（color_convolve，Saturation 0.2）
  - `minecraft:shaders/post/wobble.json`（wobble 程序：UV 波动 + 色相随时间流动）
  - `minecraft:shaders/post/spider.json`（强扭曲/模糊，蜘蛛袭击用）
  - `minecraft:shaders/post/invert.json`、`color_convolve.json` 等
- `GameRenderer.loadEffect(ResourceLocation)` / `shutdownEffect()` / `currentEffect()` 均为 public。
- `PostChain.process` 会自动把累计时间传给每个 `PostPass`，`wobble.fsh` 的 `Time` 可用。
- post JSON 的 `uniforms` 可覆盖程序默认值（如 `Frequency`、`WobbleAmount`、`Saturation`、`ColorModulate`）。

**复用决策**
- 自建两个 post JSON，复用原版已注册程序，不复制原版 shader 源码：
  - `coc:shaders/post/low_san.json`：`color_convolve`（去饱和）→ `blit`。
  - `coc:shaders/post/insane.json`：`color_convolve`（重度去饱和）→ `wobble`（波动+色相流动）→ `blit`。
- 客户端只保存自己加载的 `PostChain` 引用，关闭时判断归属，避免误关原版/其它模组效果。
- 设置开关关闭时立即 `shutdownEffect()`（仅自己的），并停止镜头晃动/暗角/低语。

**许可证/安全说明**
- 不复制、不修改原版 jar；只在运行时通过 ResourceLocation 引用原版 shader 程序。
- 自建 JSON 只包含参数配置。

## 调研 4：1.20.1 网络/存档/UI API 核对

**方法**：对本机官方名 Forge 合并 jar 执行 `javap`，确认签名，避免凭记忆写错。

**确认要点**
- `SimpleChannel` / `NetworkRegistry.newSimpleChannel` / `PacketDistributor.PLAYER` 可用。
- `SavedData` + `DimensionDataStorage.computeIfAbsent(Function<CompoundTag,T>, Supplier<T>, String)`。
- `Screen`、`ObjectSelectionList`（6 参数构造）、`Button.builder`、`EditBox`、`GuiGraphics.drawWordWrap/fill/enableScissor`。
- `ViewportEvent.ComputeCameraAngles`、`RenderGuiEvent.Post`、`ScreenEvent.Init.Post`。
- `GameRenderer.loadEffect/shutdownEffect/currentEffect`。
- `MobEffects` 1.20.1 字段名：`CONFUSION`（反胃）、`MOVEMENT_SLOWDOWN`、`DARKNESS`、`BLINDNESS`、`WEAKNESS` 等。
- `SoundEvents.AMBIENT_CAVE` 是 `Holder.Reference<SoundEvent>`，播放时用 `.value()` 或 `SimpleSoundInstance.forUI(Holder, ...)`。

**结论**
- 按确认过的签名编码；不引入 AccessTransformer/Mixin（降低构建与兼容风险）。

## 2026-11-20 · 玩家剧本导入

- 检索/评估：Minecraft 没有内置文件选择器；AWT `FileDialog` 在桌面环境可用，但会阻塞调用线程，不能在渲染线程直接打开。
- 结论：使用 AWT `FileDialog`，在独立 daemon 线程打开/读取，完成后 `Minecraft.execute` 回主线程发送网络包；无桌面/headless 时给出提示。
- 复用：Gson（已用于事件/剧本加载）、`EventDef`/`ScenarioDef`/`ScenarioAct` 标准模型、`EventRegistry.reload()`。
- 新增原创：`ScenarioImportService` 简化格式 DTO、校验、标准 JSON 生成、原子写入/失败清理；`ImportScenarioScreen`。
- 未复用：内部完整 EventDef 格式（会带 effects/spawn 风险），改为纯文本简化格式。

## 2026-11-20 · 中英双语

- 语言机制：复用 Minecraft 自带语言选择，不新增独立语言开关；`CocLang` 读取 `LanguageManager.getSelected()`。
- 翻译组织：以中文原文作为 key，独立 `coc_en.json` 映射到英文；避免改动事件/剧本 JSON 结构，导入英文内容可直接透传。
- 翻译范围：客户端 UI、服务端聊天、技能/职业、状态/恐惧症/狂躁症、低语、内置三剧本相关文本；随机事件未在剧情书展示，未作为重点。
- 聊天：客户端 `ClientChatReceivedEvent.System` 做精确/短语翻译，服务端不需要知道玩家语言。
- 翻译为人工/AI 辅助的 fan translation；专有名词与语气以可玩性优先。
