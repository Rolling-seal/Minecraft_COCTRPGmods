# 玩家与 KP 操作速查（v2.3.1）

> 一句话：**KP 负责世界、掷骰、幕布、剧情书与状态；玩家只负责角色行动与描述。**
> 玩家不自行掷骰，也不会收到事件卡选项。

---

> **中英双语（同一 jar）**：客户端语言为 English 时自动显示英文，简体中文时显示中文。英文说明见 `18-English-Guide.md`；英文界面/剧情截图见 `截图/43`~`49`。

## 一、开局

### KP
1. 确认 `mods\coc-2.3.1.jar` 已加载；玩家建卡。
2. 按 `K` 打开面板，确认五页：玩家 / 掷骰 / 道具 / 剧情书 / 工具。
3. 剧情书页选剧本（推荐先鬼屋/无光）→ 开始剧本。
4. 玩家会收到序幕幕布；口述开场，问动机。

### 玩家
1. 按 `C` 建卡；记 SAN / HP / MP / 幸运。
2. 按 `J` 看线索；角色卡底部“背景”看自己的背景。
3. 不要找掷骰键——需要检定就告诉 KP 你要做什么。
4. 每一幕开始会看到幕布：发生了什么 + 最多三个只读选项；不能点击，由 KP 裁定。

---

## 二、跑团循环

1. KP 描述：一个画面 + 一个声音/气味 + 一个可互动点。
2. KP 问：“你们先看哪里/谁走在前面/你想怎么做？”
3. 玩家自由描述行动。
4. KP 判断：
   - 合理无风险 → 直接成功；
   - 有风险 → KP 面板掷骰页选中玩家 → 选技能/难度/奖惩 → “为选中玩家掷骰”。
5. 结果公开；KP 描述成功/失败后果。
6. 玩家推进到下一场景 → KP 在剧情书选中该幕 → “向玩家显示此幕”。
7. 玩家看幕布介绍和只读选项；KP 口述后果，不点自动结算。

---

## 三、KP 面板五页

| 页 | 用途 |
|---|---|
| 玩家 | 选人；查看角色卡；状态调整/燃运；恢复神志/神志不清；成长；角色卡 JSON；删除角色。 |
| 掷骰 | 为选中玩家公开掷技能；公开掷任意骰；显示最近结果。 |
| 道具 | 看背包；发放道具；选中道具做公开使用检定。 |
| 剧情书 | 选剧本；开始/结束；打开主线/支线剧情之书；显示某幕。 |
| 工具 | 发线索；广播；重载。 |

## 四、玩家行动 → KP 操作

| 玩家说 | KP 操作 |
|---|---|
| “我检查墙/听门后/翻抽屉” | 掷骰页 → 选侦查/聆听/图书馆等 → 公开掷骰 |
| “我问他/我骗他/我安慰他” | 掷骰页 → 说服/魅惑/心理学/恐吓 |
| “我要打/躲/开枪” | 掷骰页 → 格斗/闪避/射击；结果公开 |
| “我用这个道具” | 道具页 → 选中道具 → 输入目标值 → 使用选中道具 |
| “我给他一点东西/我收下金币” | 道具页 → 发放/使用；或工具页发线索 |
| “我们进下一幕/去教堂/下井” | 剧情书 → 选幕 → 向玩家显示此幕 |
| “我掉了 SAN/受伤了” | 玩家页 → 状态调整/燃运 |
| “我想看他的背景” | 玩家页 → 查看角色卡 → 背景 |

## 五、公开掷骰

- KP 面板 → 掷骰页：
  - 选中玩家（玩家页或列表）；
  - 选技能；
  - 难度按钮循环：常规 → 困难 → 极难；
  - 奖励/惩罚按钮循环：无 → +1 → +2 → −1 → −2；
  - “为选中玩家掷骰”。
- 所有在线玩家收到聊天 + 屏幕浮层。
- 任意骰：输入 `1d100` / `2d6+3` → “公开掷骰”。
- 玩家不能自己掷；旧 `R` 键和 `/coc roll` 已移除。

---

## 六、幕布与剧情书

- **幕布**：剧本名、第 N 幕/共 N 幕、标题、发生了什么、最多三个只读选项、继续；选项不能点击。
- **剧情书主线**：每幕概要、触发、描述、可能走向（选项/检定/成功/失败）、可触发支线。
- **剧情书支线**：触发条件、所属幕、描述、选项与后果。
- 每个选项标注成功/失败/直接结果的线索；没有则显示“无线索”。
- 线索行可点击：选择在线玩家发送，线索进入其日志。
- “向玩家显示此幕”发幕布（含只读选项）；支线不自动发，由 KP 口述。

---

## 七、道具

### 发放
玩家页选人 → 道具页 → 发放道具 → 选常见道具/自定义 ID + 数量 → 发放。
配置规则时可填 **自定义名称**；之后发放的同一物品会保留该名称，列表显示 `★ 名称`。

### 使用
道具页选背包道具 → 目标值 1~100 → 使用选中道具（公开检定）。
服务端取走 1 件并公开 d100；后果由 KP 描述。
已配置规则的物品自动使用规则技能/目标；规则在“发放道具 / 规则”里配置，详见 `17-KP道具库与规则.md`。

## 八、状态调整 / 燃运

玩家页 → 状态调整 / 燃运：
- SAN/HP/MP/幸运输入 + 设置全部；
- HP/MP/幸运 −5/+5；
- HP/MP 全满。

## 八点二、KP之书与全局设置

- **KP之书**：KP 进服自动获得，无需合成；右键打开 8 页操作指南。
- **全局设置**：比较器 + 金锭 + 红石 + 书；右键设置新角色的职业点/兴趣点/技能点总上限、初始幸运/血量/SAN 范围，以及是否允许玩家分配点数。
- **剧本之书**：开始剧本后自动获得/更新，右键快速翻阅当前剧本每一幕。
- 在KP之书左侧直接点击 **“全局设置”** 条目即可打开设置面板，不用额外拿物品。
- 三者都仅 KP 可用，也在创造模式“工具与实用物品”页。

## 八点二五、角色卡内联背景

- 角色卡左栏直接显示背景六项与备注，排在“伤口”下面。
- 左侧面板滚轮向下查看；底部有提示和滚动条。
- 不再需要单独的“背景”按钮。

## 八点三、角色卡 JSON

- 玩家页选人 → **角色卡 JSON** → 导出/导入 `.json`。
- 导出是备份；导入会覆盖选中玩家的角色卡。
- 格式见 `21-角色卡JSON格式.md`。

## 八点五、玩家导入剧本

- 玩家：`J` → **导入剧本**。
- KP：`K` → 剧情书 → **导入剧本**。
- 点“选择 JSON 文件”，选中 `.json`。
- 成功后剧情书多出剧本；格式见 `16-玩家剧本导入格式.md`。

## 九、按键与命令

| 按键 | 功能 |
|---|---|
| `C` | 角色卡（底部“背景”） |
| `J` | 线索日志 |
| `K` | KP 面板（仅 KP） |

```text
/coc sancheck 1 1d6 玩家名
/coc san set 50 玩家名
/coc hp set 10 玩家名
/coc luckstat 60 玩家名
/coc scenario start dark_whispers
/coc scenario act dark_whispers 7
/coc scenario next
/coc scenario stop
/coc handout 文本
/coc growth 玩家名
/coc delete 玩家名
/coc delete 玩家名 confirm
```

已移除：`/coc roll`、`/coc check`、`/coc oppose`、`/coc push`、`/coc luck`、`/coc event ...`、`/coc config random|interval`。

## 十、常见错误

### KP
1. 连续点幕/点“向玩家显示此幕” → 玩家只看介绍，节奏由你口述控制。
2. 每个动作都掷骰 → 合理动作直接成功。
3. 失败就“什么都没发生” → 给代价/线索/更糟的选择。
4. 把剧情书当玩家菜单 → 书是 KP 参考，玩家自由行动。
5. 忘记公开结果 → 掷骰页的结果自动对所有玩家公开。
6. 用自动事件卡 → v2.0.0 已无事件卡；用剧情书 + 口述。

### 玩家
1. 等系统给选项 → 直接说“我想做什么”。
2. 自己找掷骰键 → 没有；告诉 KP 你要检定什么。
3. 只报技能名 → 先描述行动，KP 判断是否检定。
4. 不和队友交流 → 分工、共享线索。
5. 不舒服却不说 → 用 X-card/暂停/关特效。
