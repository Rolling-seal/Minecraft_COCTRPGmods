# 玩家剧本导入格式（v2.2.0）

> 适用：`coc-2.2.0.jar`。
> 玩家可以选择一份符合本格式的 `.json` 文件导入；导入成功后，KP 的剧情之书会多出这个剧本。
> 不需要改 jar、不需要重启服务器、不需要手动放文件。
> 英文版规范：`19-Scenario-Import-Format-Spec-EN.md`；可直接导入的示例：`示例/example_scenario.json`。

---

> **中英双语（同一 jar）**：客户端语言为 English 时自动显示英文，简体中文时显示中文。英文说明见 `18-English-Guide.md`；英文界面/剧情截图见 `截图/43`~`49`。

## 一、入口

玩家：
1. 按 `J` 打开线索日志；
2. 点左下角 **“导入剧本”**；
3. 点 **“选择 JSON 文件”**，在文件选择器里选中 `.json`；
4. 看到“已导入剧本……”即可；告诉 KP 刷新/重新打开剧情书。

KP：
- `K` → 剧情书 → **导入剧本**，同样操作。

> 也可以点“生成示例文件”，会在 `config/coc/example_scenario.json` 生成模板；用记事本修改后再选择它导入。

---

## 二、最小格式

```json
{
  "format": "coc-scenario-v1",
  "id": "my_story",
  "title": "我的剧本",
  "description": "一句话简介",
  "intro": "玩家开场看到的幕布文字。",
  "outro": "结局幕布文字。",
  "sanReward": "1d10",
  "acts": [
    {
      "title": "雨夜",
      "summary": "KP 参考：玩家抵达村庄。",
      "trigger": "玩家进入村庄时",
      "description": "你们在雨夜里抵达村口。教堂没有灯。",
      "options": [
        {
          "text": "检查教堂",
          "skill": "spot_hidden",
          "difficulty": "regular",
          "success": "你在门缝里看到一排湿脚印。",
          "successClue": "旧邮戳来自二十年前的盐沼镇。",
          "failure": "你只闻到潮湿的木头味。"
        }
      ],
      "sideEvents": [
        {
          "title": "支线：钟楼上的水声",
          "trigger": "玩家靠近钟楼时",
          "description": "水声停了。你听见有人在楼上数数。",
          "options": [
            {
              "text": "上楼查看",
              "skill": "listen",
              "difficulty": "regular",
              "success": "你听出数数声在模仿你的呼吸。",
              "failure": "楼梯在你脚下断了一级。"
            }
          ]
        }
      ]
    },
    {
      "title": "地下",
      "summary": "玩家进入地窖，面对最终选择。",
      "trigger": "玩家打开地窖门时",
      "description": "地窖深处亮着一盏不该亮着的灯。",
      "options": [
        {
          "text": "熄灭它",
          "skill": "occult",
          "difficulty": "hard",
          "success": "灯灭了，黑暗里有人松了口气。",
          "failure": "灯芯爆出一阵蓝火。"
        }
      ]
    }
  ]
}
```

> 幕标题不要自己写“第一幕：”，界面会自动加“第 1 幕 · …”。写成“雨夜”“地下”即可。
>
> 线索只写内容，不要自己加“线索：”前缀；剧情书会自动显示“成功线索：/失败线索：/线索：”。留空或写 `""` 会显示“无线索”。

## 三、字段说明

### 顶层

| 字段 | 必填 | 说明 |
|---|---|---|
| `format` | 建议 | 固定 `coc-scenario-v1`；不是这个值会被拒绝。 |
| `id` | 是 | 3~32 位小写字母/数字/下划线，字母开头；例如 `my_story`。不能与内置/已导入剧本重复。 |
| `title` | 是 | 剧本名，最多 80 字。 |
| `description` | 否 | 简介，最多 1000 字。 |
| `intro` | 否 | 序幕幕布文字，最多 4000 字。 |
| `outro` | 否 | 结局幕布文字，最多 4000 字。 |
| `sanReward` | 否 | 结局 SAN 奖励，默认 `1d10`；支持 `0`、`1d6` 等。 |
| `acts` | 是 | 1~24 幕。 |

### `acts[]`

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 幕标题，最多 80 字；不要自带“第N幕”。 |
| `summary` | 否 | 给 KP 看的大致走向，最多 500 字。 |
| `trigger` | 否 | 什么时候该显示这一幕，最多 500 字。 |
| `description` | 是 | **玩家幕布上看到的介绍**，最多 4000 字；不要写选项。 |
| `options` | 否 | 最多 8 个；这是剧情书里给 KP 参考的走向，不会自动发给玩家。没有就写空数组或省略。 |
| `sideEvents` | 否 | 最多 8 个支线；同上，只进剧情书。 |

### `options[]`

| 字段 | 必填 | 说明 |
|---|---|---|
| `text` | 是 | 选项/行动描述，最多 300 字。 |
| `skill` | 否 | 技能 id，例如 `spot_hidden`、`listen`、`occult`；不写表示无检定。可用中文技能名。 |
| `difficulty` | 否 | `regular` / `hard` / `extreme`，或 `常规` / `困难` / `极难`；默认 regular。 |
| `success` | 否 | 成功后果文字，最多 2000 字。 |
| `failure` | 否 | 失败后果文字，最多 2000 字。 |
| `outcome` | 否 | 无检定/直接结果文字，最多 2000 字。 |
| `clue` | 否 | 该选项成功（无技能时为直接结果）获得的线索文字；不写/留空表示没有线索。 |
| `successClue` | 否 | `clue` 的别名；同时存在时优先它。 |
| `failureClue` | 否 | 失败时获得的线索；不写/留空表示失败没有线索。 |

### `sideEvents[]`

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 支线标题，最多 80 字。 |
| `trigger` | 否 | 怎么触发，最多 500 字。 |
| `description` | 是 | 触发后的场景，最多 4000 字。 |
| `options` | 否 | 同上面 options，最多 8 个。 |

---

## 四、限制与安全

- JSON 最大 **64KB**；最多 **24 幕**；每幕最多 **8 个选项 + 8 个支线**。
- 只接受文本、技能 id、难度、成功/失败/结果文字。
- **不会执行** effects、物品、生成生物、命令、脚本；写了也会被忽略。
- `id` 不能覆盖内置剧本；重复 id 会被拒绝，换一个即可。
- 导入会写入服务器 `config/coc/scenarios/` 与 `config/coc/events/`，并在服务端重载；世界重启后仍然存在。
- 导入后所有在线玩家会看到“【剧本导入】某某添加了……”；KP 的剧情书面板会自动刷新。
- 玩家导入不需要 OP；如果服务器不想开放，可在后续版本加配置开关（当前默认允许）。

---

## 五、导入后怎么用

1. KP `K` → 剧情书 → 选择新剧本；
2. **主线剧情**：选幕 → “向玩家显示此幕”（只发幕布）；
3. **支线剧情**：看触发/后果，由 KP 口述；
4. 需要检定：`K` → 掷骰 → 公开掷；
5. 结局：`/coc scenario next` 或剧情书结束。

---

## 六、删除/修改导入的剧本

服务端目录：

```text
config/coc/scenarios/<id>.json
config/coc/events/import_<id>_a1.json
config/coc/events/import_<id>_a1_s1.json
...
```

- 修改：改这些 JSON 后 `/coc reload`。
- 删除：删掉对应文件后 `/coc reload`。
- 不建议直接改内置资源；内置剧本在 jar 内。

---

## 七、常见错误

| 提示 | 处理 |
|---|---|
| `id 必须为...` | 改成小写字母/数字/下划线，字母开头，例如 `my_story`。 |
| `剧本 id 已存在` | 换一个 id。 |
| `acts 不能为空` | 至少写 1 幕。 |
| `第 N 幕缺少 description` | 每一幕都要有玩家幕布介绍。 |
| `技能不存在` | 用 `/coc skill` 可查的技能 id；或先留空。 |
| `JSON 语法错误` | 检查逗号、引号、括号；建议用记事本/JSON 校验器。 |
| `JSON 超过 64KB` | 精简描述或拆成多个剧本。 |
