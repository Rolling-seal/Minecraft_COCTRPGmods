# 新手 KP 带团指南（玩家也是新手）

> 目标：让流程像“一起讲故事”，而不是“KP 念剧本、玩家点选项、掷骰卡关”。
> 适用：本模组《克苏鲁的呼唤》1.20.1 · 2～3 小时短团。

---

> **v2.0.0 操作变更（务必先读）**：本文件写作时仍按旧“事件卡/选项/自动结算”流程。v2.0.0 已删除事件卡：
> - 每一幕只用 `K → 剧情书 → 主线剧情 → 向玩家显示此幕` 发幕布；
> - 支线用 `K → 剧情书 → 支线剧情` 查看触发/后果，由 KP 口述；
> - 掷骰用 `K → 掷骰` 公开进行，玩家不再按 `R`；
> - 道具/状态/背景见 `15-KP七功能与幕布剧情书.md`。
> 下文可作为剧情内容与带团节奏参考；涉及“事件页/事件卡/自动结算/下一幕自动发卡”的步骤，一律按上述替换。


## 一、先记住三句话

1. **跑团是共同创作**：KP 准备的是“ situation（局面）”，不是“必须走完的台词”。
2. **检定只在结果不确定、失败有代价时**：不要每个动作都掷骰。
3. **失败要推动剧情，不是卡住剧情**：失败给代价、给新线索、给更糟的选择。

---

## 二、让流程不死板的 8 个做法

### 1. 开场先问三个问题，让玩家“入股”
不要一上来读一大段背景。先问：
- “收到信的时候，你正在做什么？”
- “你为什么非回这个村子不可？”
- “你最怕在村里遇见谁？”

玩家的回答直接变成后续剧情素材。NPC、幻觉、结局都可以回扣这些回答。

### 2. 每幕只准备“1 个场景 + 3 个可互动点 + 1 个选择”
例如村庄：
- 场景：空无一人的村口，井边有滴水的木桶。
- 可互动点：井、教堂、还亮着灯的窗户（任选，不强制顺序）。
- 必须做的选择：先查井、先进教堂，还是先敲门？

**不要设计“唯一正确顺序”**。玩家先去哪，哪就是主线。

### 3. 三线索原则
每个关键结论至少给 **3 条线索 / 3 种获取方式**：
- 一个靠观察（侦查/聆听）
- 一个靠交谈（说服/心理学/话术）
- 一个靠环境（物品、书、尸体、声音）

玩家漏掉一条，故事仍能继续。

### 4. 失败不是“什么都没发生”
失败时给三选一：
- **代价**：受伤、掉 SAN、被发现了、失去物品。
- **新线索**：失败时反而看到更可怕的东西。
- **更糟的选择**：门打不开，但窗子可以爬；爬窗会惊动里面的东西。

话术：
> “你失败了。你没有打开锁，但你听见门后有人把钥匙拔走了——现在你必须想别的办法。”

### 5. 用“是，但是 / 不，而且”回应创意
玩家说“我想把油灯扔进地窖”：
- 不要只说“不行”。
- 说：“可以，但是地窖里有沼气，火焰会比你想象的大。你确定？”
- 或者：“可以，而且火光会照亮墙上的东西，但也会让里面的东西看见你。”

### 6. 让玩家描述成功与失败
掷骰后不要只报“成功/失败”，问：
- “这一枪打中了哪里？”
- “你躲开时撞到了什么？”
- “你看见什么让你确定自己失败了？”

玩家描述得越多，场面越不僵硬。

### 7. 控制检定数量
2～3 小时新手团，**6～10 次技能检定 + 2～4 次 SAN 检定**通常足够。
- 普通、合理、无风险的动作：直接成功。
- 只有“可能失败、失败有意义”时才掷。
- 战斗/追逐要短：2～3 轮解决，不要打半小时。

### 8. 先裁定，后查书
新手 KP 不需要背完整规则：
- 记得：`d100 ≤ 技能` 成功；`≤ 技能/2` 困难；`≤ 技能/5` 极难；`01` 大成功，`100` 大失败。
- 不确定的规则先按常识裁定，团后再查。不要现场翻书五分钟。

## 三、可直接用的《黑暗中的低语》2.5～3 小时流程（十二幕）

完整读文本、每幕线索和失败后果见 `08-黑暗中的低语带团手册.md`；这里只给节奏。

### 准备（5 分钟）
1. 让玩家创建角色；至少写一个“为什么回村”的理由。
2. v2.0.0 随机事件已停用，不需要关闭。
3. 发放开场信：KP 面板 → 工具 → 发放线索，或 `/coc handout ...`。

### 十二幕速览
1. **信**：读信，问“为什么回来”；检查信封/出发/烧信。
2. **村庄**：井、教堂、亮灯的窗；任选两个得到“地下有东西”。
3. **井**：打水/听井底/投石；童鞋、铜钥匙、敲击。
4. **教堂**：铭文、告解室、祈祷；长椅上的人同时抬头。
5. **告解**：日记给真名“伊奥斯”；暗格给画像草图。
6. **墓地**：自家旧坟、新坟草人；村里献祭名字。
7. **地下**：潜行/火把/闯入；石台人形与你的信。
8. **石台**：检查信/画像/触碰人形；一次 SAN。
9. **梦**：海底城市与门；一次 SAN；带回门/真名。
10. **守梦人**：仪式；打断/混入/躲藏。
11. **真名**：念名/烧画/逃跑；至少两种解法。
12. **黎明**：烧教堂/封地窖/带走证据/离开；收尾。

### 节奏
- 每幕先描述画面，再问“你们先看哪里/谁走在前面”。
- 玩家自由行动、对话、调查；需要时再检定。
- 所有玩家做完这一幕的事，KP 在剧情书里选中下一幕，点“向玩家显示此幕”；玩家跳场景时同样直接显示对应幕。
- 支线（窗后的孩子/下井/牧师房间/夜宿/取画像）在 `K → 剧情书 → 支线剧情` 查看触发与后果，由 KP 口述。
- 终幕之后用 `/coc scenario next` 结束剧本，自动 SAN 奖励；再 `/coc growth`。

### 收尾（10 分钟）
- 问三个问题：最印象深刻的画面？最想继续查什么？角色现在最怕什么？
- 用最后一个答案做下一团钩子。

## 四、玩家卡住时怎么办

不要替他们做决定，给“推动”：
- 一个声音：远处钟响、井底敲击、有人叫名字。
- 一个 NPC 行动：村民关门、孩子递来纸条。
- 一个新线索：风吹开一页日记、尸体手里攥着东西。
- 一次环境变化：灯灭、起雾、雨突然变大。
- 直接问：“你此刻最想确认什么？”然后围绕那个方向给线索。

如果玩家一直不动，才用随机事件/强制事件推一下；不要连续用。

## 五、五个不要

1. 不要每个动作都让掷骰。
2. 不要把所有线索藏在一个检定后面。
3. 不要让失败等于“无事发生”。
4. 不要连续读超过 3 分钟的背景文本。
5. 不要在玩家正投入互动时，用随机事件打断。

## 六、五个可以

1. 可以让合理的行动直接成功。
2. 可以让玩家自己描述成功/失败。
3. 可以把失败变成代价或新线索。
4. 可以让玩家决定场景顺序。
5. 可以随时调整剧本，只要保留“核心真相”。

## 七、本模组的快捷操作

| 目的 | 操作 |
|---|---|
| 开团前关随机事件 | 不需要（v2.0.0 随机事件已停用） |
| 发放开场信/线索 | KP 面板 → 工具 → 发放线索；或 `/coc handout ...` |
| 推进剧本 | KP 面板 → 剧情书 → 向玩家显示此幕 |
| 关键时刻 SAN 检定 | `/coc sancheck 1 1d6 玩家名` |
| 玩家状态异常 | KP 面板 → 玩家 → 恢复神志/治疗/SAN 调整 |
| 结团成长 | `/coc growth 玩家名` |
| 玩家怕特效 | 暂停菜单 → 克苏鲁设置 → 关闭低 SAN 特效 |

## 八、一页速查

- 每个场景：**1 个感官细节 + 1 个可互动对象 + 1 个代价/选择**。
- 每个关键结论：**至少 3 条线索**。
- 每 10～15 分钟：**一个新信息或一个必须做的决定**。
- 每次检定前：**告诉玩家目标值**（“你侦查 60，常规成功需要 60 以下”）。
- 每次失败后：**加代价或加线索**，不要停。
- 每团结束：**问感受、给奖励、留钩子**。
