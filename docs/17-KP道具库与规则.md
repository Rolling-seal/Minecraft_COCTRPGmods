# KP 道具库与规则（v2.0.0）

> 适用：`coc-2.0.0.jar`。
> 作用：KP 按物品 ID 把物品加入“道具列表”，并为每件物品配置 **使用技能 + 目标点数**。
> 配置持久化到服务端 `config/coc/items.json`，重启后仍在。

---

> **中英双语（同一 jar）**：客户端语言为 English 时自动显示英文，简体中文时显示中文。英文说明见 `18-English-Guide.md`；英文界面/剧情截图见 `截图/43`~`49`。

## 一、在哪里配置

KP `K` → **道具** → **发放道具 / 规则**。

打开后：
- 左侧是道具列表：常见道具 + 已加入道具库的自定义物品；
- 已配置规则的物品前面有 `★`，右侧显示“技能 目标”，例如 `侦查 65`；
- 选中物品后点 **“配置选中规则”**；
- 输入自定义 ID 后点 **“配置自定义（加入列表）”**，保存规则即加入列表；
- “发放选中 / 发放自定义”仍然可以直接把物品给当前玩家。

也可以从 Keeper 道具页选中背包物品，点 **“配置选中道具规则”** 直接打开同一配置界面。

---

## 二、规则界面

字段：
- **技能 ID（可空）**：例如 `spot_hidden`（侦查）、`listen`（聆听）、`occult`（神秘学）、`medicine`（医学）；留空表示无技能。
- **目标点数（1~100）**：使用这件物品时 d100 的目标值。

保存后：
- 物品加入/更新到道具库；
- KP 道具列表显示 `★` 和规则；
- 使用该物品时，系统自动使用规则中的技能名与目标点数；
- 没配置规则的物品仍使用“使用选中道具”页面上的临时目标值。

> 技能 ID 只用于显示与记录；判定目标以“目标点数”为准，不自动套用玩家技能值。

---

## 三、使用流程

1. 玩家页选中玩家；
2. 道具页选中玩家背包里的物品；
3. 点“使用选中道具（公开检定）”；
4. 服务端：
   - 从背包取走 1 件；
   - 查 `items.json` 中该物品的规则；
   - 有规则：使用规则技能名 + 规则目标点数；
   - 无规则：使用页面上的临时目标值；
   - 掷 d100，对所有玩家公开结果；
5. 成功/失败后果由 KP 描述。

实测聊天示例：
```text
【Tester · Torch · 侦查】 21 / 65 → 困难成功
道具：Torch；技能 侦查；规则目标 65；已从 Tester 的背包取走 1 件。
```

---

## 四、数据文件

`config/coc/items.json`：

```json
{
  "items": [
    {
      "id": "minecraft:torch",
      "skill": "spot_hidden",
      "target": 65
    }
  ]
}
```

- `id`：已注册物品 ID；
- `skill`：技能 ID，可空；
- `target`：1~100。
- 可手动编辑后重启服务器，或在游戏内配置。

## 六、注意

- 道具库是服务器级配置，所有 KP 共用。
- 规则不会自动执行物品效果；只影响公开检定的技能名与目标点数。
- 修改规则不会改变已经发放到玩家背包里的物品；只影响之后的使用。
- 删除规则：编辑 `config/coc/items.json` 删除对应条目，重启服务器；当前没有游戏内删除按钮。
